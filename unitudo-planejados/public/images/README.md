# Origem dos recursos

As sete composições `living`, `kitchen`, `bedroom`, `closet`, `office`, `detail` e `integrated` foram geradas nesta tarefa com a ferramenta image_gen, em 19/10/2026, como referências conceituais de interiores sem marcas, pessoas ou projetos de clientes. Convertidas localmente para WebP. Não são fotografias reais da Unitudo nem materiais obtidos de redes sociais.

Nenhuma imagem de terceiros foi copiada. Uso sujeito aos termos da ferramenta geradora. Não se alega licença de banco fotográfico, exclusividade ou autoria de obra executada. O fallback SVG foi desenhado para o protótipo. As fontes locais DM Sans e Instrument Serif usam SIL Open Font License, copiadas em `../licenses/`.
